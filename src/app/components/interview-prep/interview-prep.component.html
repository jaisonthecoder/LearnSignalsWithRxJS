📖 Study Guide & Quick Reference

🔥 Key Concepts

  • Signals: Synchronous reactive primitives
  • Computed: Derived state calculations
  • Effect: Side effect handling
  • WritableSignal: Mutable signal state
  • ReadonlySignal: Immutable signal access

⚡ Performance Tips

  • Use computed() for derived state
  • Prefer signals for local state
  • Keep RxJS for async operations
  • Batch signal updates when possible
  • Use readonly() for external access

🚀 Migration Strategy

  • Start with simple component state
  • Convert BehaviorSubject to signal
  • Replace pipe() with computed()
  • Use effect() for side effects
  • Keep async operations in RxJS

🧪 Testing Approach

  • Use TestBed.runInInjectionContext()
  • Test signal updates directly
  • Mock signal dependencies
  • Verify computed calculations
  • Test effect side effects

💡 Interview Success Tips

🎯 Technical Focus

Emphasize understanding of when to use which tool. Show knowledge of both RxJS and Signals strengths and weaknesses.

🔧 Practical Examples

Be ready to write code examples. Practice converting between RxJS and Signals approaches for common scenarios.

📊 Performance Awareness

Discuss performance implications. Mention change detection, memory usage, and when optimization matters.

🏗️ Architecture Thinking

Show understanding of how Signals fit into larger application architecture and state management patterns.
